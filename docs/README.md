# OctoAcme Project Management Docs

This README provides a concise summary of OctoAcme's project management processes and direct links to the detailed guidance stored in the `docs/` folder.

## Project management overview

OctoAcme follows a lightweight, iterative delivery lifecycle:

1. Initiation — validate the problem, align stakeholders, and confirm go/no-go for planning.
2. Planning — define scope, backlog, milestones, dependencies, and the definition of done.
3. Execution — deliver increments, manage work in progress, review progress, and address blockers.
4. Release — validate readiness, deploy safely, and communicate changes to stakeholders.
5. Retrospective — capture lessons learned and turn them into follow-up improvements.

The operating model is grounded in a few core principles:

- Customer-first prioritization and measurable outcomes
- Iterative delivery with small, testable increments
- Clear ownership across PM, Product Lead, and delivery team
- Data-informed decisions and tracking of progress and risks
- Psychological safety and continuous improvement

Core project artifacts include the project one-pager, roadmap and release plan, backlog with acceptance criteria, risk register, and retrospective notes.
